# 第三部分：AI 驱动的科研新范式

前两部分分别补齐 AI 与 Science 的语言，第三部分把它们放回真实科研流程。这里的“新范式”不是简单增加一个聊天机器人，而是重新设计知识获取、问题提出、计算、实验、反馈和证据管理之间的连接方式。

```text
文献与已有数据
      ↓
问题与可检验假设
      ↓
计算研究 ──→ 实验设计 ──→ 执行与观测
   ↑                         ↓
   └──── 模型更新与下一步决策 ←┘
      ↓
证据综合、写作、评审与传播
```

人类研究者贯穿整个循环：设定问题和价值目标、审查证据、处理异常、承担安全与科研诚信责任。

## 先区分三个层级

| 层级 | 系统能够做什么 | 不能据此声称什么 |
| --- | --- | --- |
| 自动化 | 按预设步骤执行检索、计算、实验或记录 | 系统理解了研究问题 |
| 自治 | 在明确目标和边界内，根据反馈选择下一步动作 | 系统能在开放世界中独立做科学 |
| 科学发现 | 产生并经独立证据支持的新知识 | 一次模型输出或一次命中就是发现 |

自治是系统属性，发现是经过科学共同体检验的知识主张；两者不能混用。

## 合流后的共同方法

无论从哪条路线进入，本部分都坚持五条共同原则：

1. **来源可追踪：**任何重要主张都能回到原始数据、代码或文献；
2. **假设可检验：**系统输出要转化成可能被证据否定的陈述；
3. **过程可复现：**环境、参数、随机性、失败结果与人工修改均被记录；
4. **决策有边界：**优化目标、约束、停止条件和人工接管点写在执行前；
5. **结论分层级：**区分模型结果、实验观察、解释性假设与已建立知识。

## 为什么不从“科研 Agent 工具清单”开始

工具更新很快，科研有效性的标准变化更慢。一个系统即使会调用搜索、代码和仪器，也可能检索错文献、优化错目标、掩盖失败结果或给出无法验证的解释。因此本部分按科研环节和证据责任组织，工具只作为实现手段出现。
