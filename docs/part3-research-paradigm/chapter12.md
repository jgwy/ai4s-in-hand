# 第 12 章：科研知识与文献智能

> [!CAUTION]
> 本章是可公开审阅的 Alpha 初稿，检索示例核验于 2026-08-10。数据库覆盖、排序算法和在线页面会变化；检索日志记录的是可复查过程，不承诺任何一次检索已经穷尽文献。

科学研究通常从“已知什么”开始，但搜索框返回的不是知识，只是候选记录。真正可用于提出问题的产物必须回答：查了哪里、为什么纳入、每项主张由哪段证据支持、反例在哪里、版本是否已更正。大模型可以帮助扩展关键词和整理表格，却不能替代这些责任。

## 本章解决的问题

完成本章后，你应该能够：

1. 把宽泛主题改写成可检索、可回答的问题；
2. 组合关键词检索、语义检索与前后向引用追踪；
3. 保存可复现检索日志，并说明数据库覆盖边界；
4. 用证据矩阵区分论文报告、作者解释与自己的综合判断；
5. 检查标题、作者、载体、年份、DOI、版本和更正或撤稿状态；
6. 把 RAG 输出当作待核验草稿，而不是文献事实的裁决者。

## 核心概念

### 12.1 先固定问题，再打开搜索框

一个可检索问题至少写清四项：对象 $O$、干预或方法 $M$、比较 $C$、结局与条件 $Y$。例如：

> 在有限候选池的材料序贯筛选中（$O$），贝叶斯优化（$M$）相对随机选择（$C$），是否在相同查询预算与初始样本下更早找到高目标值候选（$Y$）？

这比“贝叶斯优化好不好”更可回答，也暴露了必须控制的预算、初始化、候选池和评价指标。搜索前再写纳入与排除标准，避免看到结果后改变口径。PRISMA 2020 要求系统综述透明报告检索与筛选过程；本章借用其可追踪思想，但一个教学证据表不应自称完整系统综述（[Page et al., 2021](https://doi.org/10.1136/bmj.n71)）。

### 12.2 三种检索互相补漏

| 路径 | 擅长发现 | 主要盲点 |
| --- | --- | --- |
| 关键词与字段检索 | 精确术语、作者、DOI、时间范围 | 同义词、旧术语和跨领域叫法 |
| 语义检索 | 问法不同但内容相近的工作 | 排序不可解释、更新和覆盖不透明 |
| 引用追踪 | 奠基工作、后续复现、批评与更正 | 引用网络偏向较老或高可见度工作 |

实际流程是循环：先用宽查询找到“种子论文”，从标题、关键词和参考文献扩展同义词，再做前向引用、作者更正和撤稿检查。搜索摘要只用于筛选；涉及数值、比较条件或失败原因时，要读方法、结果和补充材料。

### 12.3 从论文记录到证据单元

证据单元不是一整篇论文，而是“一个限定主张 + 对应方法或结果位置 + 适用条件”。建议保存：

- 稳定标识与完整元数据；
- 研究对象、样本单位、数据生成方式和比较基线；
- 支持、反对或仅提供背景的证据；
- 论文中的限制，以及读者新增的限制；
- 原始文本位置和自己的释义，二者分栏；
- 更正、撤稿、版本更新与核验日期。

这能阻止“论文提到 X”被误写成“论文证明 X”。例如 Liang 等在五个材料实验数据集上比较了多种代理模型与采集函数，并与随机基线比较；它支持特定池式回放条件下的性能结论，不支持“贝叶斯优化在所有真实实验中必然更快”（[Liang et al., 2021](https://doi.org/10.1038/s41524-021-00656-9)）。

### 12.4 RAG、知识图谱与证据责任

检索增强生成（RAG）通常包含语料库、检索器和生成器。向量检索提高候选段落召回，重排器改善相关性，生成器组织回答；科学知识图谱则把论文、对象、方法、数据集和主张显式连接。无论结构多复杂，都要分别评价：

$$
Q_{\text{system}}=(\text{检索覆盖},\ \text{引用对应},\ \text{综合正确},\ \text{时效与版本}).
$$

2026 年 OpenScholar 论文在其多领域基准上报告了检索与引用感知流程的改进，同时明确不主张文献综合可以完全自动化，并列出语料许可、评测规模和模型变化带来的限制（[Asai et al., 2026](https://doi.org/10.1038/s41586-025-10072-4)）。因此，本教程只把 RAG 当作候选发现和草稿生成层；最终证据矩阵必须能在没有生成模型时人工复查。

### 12.5 时效、版本与更正不是附录

每个关键来源执行七项核对：标题、作者、载体、年份、稳定标识、版本、状态。A-Lab 论文是必要案例：2026 年作者更正澄清“新”是对预测平台而言，并把原先 40 项成功中的 4 项改为仅凭 XRD 无法确定；更新后的口径是 36 项确认、4 项不确定（[原论文及更新记录](https://doi.org/10.1038/s41586-023-06734-w)，[作者更正](https://doi.org/10.1038/s41586-025-09992-y)）。只抄旧摘要或旧新闻会改变教学结论。

## 可检查产物：检索日志、证据矩阵与综述骨架

### 12.6 一份可复现的检索日志

下面记录本章示例的一次查询配置。API 密钥只从本地环境变量读取，不进入日志。由于仓库没有保存当时的原始 API 响应快照或内容哈希，表中不把易漂移的返回数量和排序位次作为可复现事实。

| 字段 | 记录 |
| --- | --- |
| 问题 | 固定预算下，池式材料筛选中的 BO 相对随机选择表现如何？ |
| 检索日期 | 2026-08-10 |
| Bohrium 论文检索 | `words=[Bayesian optimization, materials science, experimental domains, random sampling baseline]`；英文问题同上；`type=1`；日期 2018-01-01 至 2026-08-10；`pageSize=10` |
| Bohrium 结果 | 返回候选中包含 Liang et al. 2021；最终纳入前解析到[正式 DOI 页面](https://doi.org/10.1038/s41524-021-00656-9) |
| 通用 Web 线索 | 查询 `benchmarking Bayesian optimization experimental materials science random baseline` |
| 一手核验 | 打开 Nature/npj 出版页，核对题名、作者、2021、文章号 188、DOI、方法、数据与代码可用性 |
| 状态检查 | 出版页核验于 2026-08-10；未见页面链接更正或撤稿。若后续复查出现更新，以新记录追加，不覆盖旧日志 |
| 纳入标准 | 同预算、有随机或固定规则基线、公开比较条件、材料实验数据或其池式回放 |
| 排除标准 | 只有宣传性加速数字、无比较预算、仅综述且无法回到原始研究 |

复现时不要要求数量或排序位置完全相同；检查查询参数、返回候选及最终纳入理由是否可追踪。若要把检索称为完整审计记录，还应脱敏保存响应快照、时间戳、内容哈希或查询 ID。网络或 API 不可用时，降级为 DOI 清单 + 出版社页面 + 人工引用追踪，核心判断不变。

### 12.7 证据矩阵模板与最小示例

| ID | 限定主张 | 直接证据与条件 | 反例/限制 | 状态 | 可写成 |
| --- | --- | --- | --- | --- | --- |
| E1 | 某些 BO 配置在五个池式材料数据集上优于随机基线 | Liang 2021，同候选池、回放评价和预定指标 | 数据集已有采样历史；不等于在线实验普遍加速 | 正式论文，2026-08-10 未见更正 | “在该基准条件下观察到……” |
| E2 | 文献 RAG 可改善多文献综合与引用 | Asai 2026，ScholarQABench 与专家评测 | 题量、学科、许可语料和模型版本有限 | 正式论文，核验于 2026-08-10 | “该系统在所报基准上……” |
| E3 | A-Lab 报告的部分自动判定需人工复核 | 2023 原文 + 2026 作者更正 | 不能据此否定所有自动分析 | 已更正 | “更正后 36 项确认、4 项不确定” |

综述骨架按“问题—一致证据—分歧—适用条件—未决问题”组织，而不是逐篇摘要。每一段先写可被证据支持的句子，再挂接 E 编号；没有 E 编号的强主张要删除或降级。

### 12.8 简单基线

高级基线是语义检索 + RAG；简单基线是一名研究者使用固定检索式、电子表格和 DOI 页面完成 10 篇候选的证据表。比较指标包括：

- 已知种子论文的召回；
- 引用是否真的支持相邻主张；
- 纳入来源的年份、方法与观点覆盖；
- 每条记录的人工核验时间；
- 发现的错误 DOI、错配版本和更正数量。

如果 RAG 只让文字更流畅，却没有改善覆盖与引用对应，它没有超过基线。

## 常见错误与失败模式

| 现象 | 根因 | 诊断与修复 | 不能推出 |
| --- | --- | --- | --- |
| 搜到很多论文但问题仍模糊 | 先搜索后定义问题 | 固定对象、比较、结局和条件 | 数量多即覆盖充分 |
| 只纳入支持预期的研究 | 查询词和筛选受确认偏差影响 | 加入失败、negative、limitation、replication 等词并做引用追踪 | 文献多数即机制成立 |
| 引用存在但不支持句子 | 生成器按主题而非证据对齐 | 打开正文定位方法或结果段 | DOI 真实即引用正确 |
| 把搜索排名当质量排序 | 排序混合相关性、可见度和模型偏好 | 独立评估设计、数据与证据 | 第一条最好 |
| 漏掉更正或正式版本 | 只读预印本、缓存或二手页面 | 回到 DOI 和出版社“updates”区域 | 旧数字仍可沿用 |
| 用“未检索到”证明“不存在” | 数据库、语言和时间覆盖有限 | 报告覆盖边界并扩展数据库 | 缺席等于反证 |

## 科学有效性与证据检查

- [ ] 问题、纳入标准和主要结局是否在筛选前写下？
- [ ] 是否同时使用精确检索、语义检索和引用追踪中的至少两种？
- [ ] 是否记录数据库、日期、完整查询、过滤条件和返回数量？
- [ ] 关键数字是否读过方法/结果，而不只来自摘要或搜索片段？
- [ ] 每项综合主张是否至少对应一个证据单元，并保留反例或限制？
- [ ] 2025—2026 新成果是否写成“在所报基准/范围内”，没有外推为已实现的通用能力？
- [ ] 是否检查 DOI、正式版本、更正、撤稿和数据更新？
- [ ] 没有外部服务时，人工基线是否仍能复查最终结论？

## 练习与评价要点

1. **概念辨析：**解释语义相关、来源质量、引用正确和科学结论为何是四个不同判断。评价要点：必须给出各自可检查的对象，不能只说“都要人工审核”。
2. **失败诊断：**给定一段含五个引用的 RAG 摘要，逐句标为“直接支持、间接背景、冲突、无法核验”。评价要点：打开原文、保留证据位置、至少发现一个适用条件。
3. **迁移实践：**围绕动力系统代理的外推可靠性，设计双通道查询并保存日志。评价要点：问题可回答、关键词含同义词、至少一个简单基线、检查版本状态。
4. **更新练习：**三个月后重跑本章查询，不覆盖旧记录。评价要点：区分新增论文、排序变化、正式版本与更正，并说明结论是否需要修改。

## 本章小结与下一步

文献智能的核心产物不是摘要，而是可重放的检索决策和可逐条审计的证据矩阵。下一章将把矩阵中的一致证据、分歧和空白转化为竞争假设与判别实验，而不是把“论文少”直接称为科学缺口。
