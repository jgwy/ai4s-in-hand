# 第 15 章：高通量实验与自动化实验室

> [!CAUTION]
> 本章只讨论系统架构、虚拟候选池和安全设计，不提供真实化学、生物或材料实验的配方、温压、剂量、设备控制或操作参数。任何真实实验都需要合格实验室、审批、专业人员、设备联锁和现场规程。

一次运行一百个样本可以是高通量；机器人照表执行可以是自动化；只有系统在预定目标和边界内读取结果、选择下一步并再次执行，才具备有限自治。三者都可能加快工作，也都可能更快地重复错误。

## 本章解决的问题

完成本章后，你应该能够：

1. 区分高通量、自动化、远程执行和自驱动实验室；
2. 画出设备、调度、数据、在线分析、决策与安全层的接口；
3. 在虚拟候选池中比较固定脚本、随机、贪心和不确定性感知策略；
4. 为异常、超限、传感失败和通信中断设计联锁与人工接管；
5. 用吞吐、数据质量、决策效率、安全和可追踪性共同评价系统；
6. 不把自动判定或一次命中直接写成科学发现。

## 核心概念

### 15.1 四个层级不能混称

| 层级 | 定义 | 例子 | 尚未具备 |
| --- | --- | --- | --- |
| 高通量 | 并行或批量提高单位时间样本量 | 对候选池批量查询隐藏标签 | 自动控制与反馈决策 |
| 自动化 | 按预设流程执行与记录 | 固定队列依次运行虚拟测量 | 根据结果改变计划 |
| 远程执行 | 人在别处下发已审核任务 | 审批后提交虚拟批次 | 系统自主选择目标 |
| 有限自治/SDL | 在边界内根据反馈选择下一批 | 代理模型 + 采集函数 + 虚拟 oracle | 开放世界独立科学发现 |

自驱动实验室的综述通常把自动化平台、在线分析和实验规划/机器学习闭环作为关键组成（[Abolhasani & Kumacheva, 2023](https://doi.org/10.1038/s44160-022-00231-0)）。这是一种系统集成定义，不是对系统“理解力”的证明。

### 15.2 七层安全架构

```text
研究目标与人工审批
        ↓
决策层：候选选择、预算、停止规则
        ↓
调度层：队列、资源、重试与优先级
        ↓
执行适配层：统一命令和状态接口（本章仅虚拟）
        ↓
观测层：虚拟传感、校准标记、质量码
        ↓
数据层：不可变原始记录、样本身份、provenance
        ↓
独立安全层：允许域、联锁、急停、人工接管
```

安全层不能依赖优化器“记得遵守”。它应独立拒绝越界动作，即使决策器、网络或数据层出错。控制命令使用白名单；默认失败为停止；重试次数有限；任何人工覆盖都追加记录。

### 15.3 数据流水线与样本身份

闭环中的每条观测至少包含候选 ID、批次、时间、虚拟设备版本、原始值、质量码、处理版本和不确定性。在线分析输出不能覆盖原始数据。若样本身份错位，算法会把一个候选的反馈学到另一个候选上；这通常比单次预测误差更难被发现。

### 15.4 调度与决策分离

调度器回答“已批准任务以什么顺序使用资源”，决策器回答“下一批候选是什么”。分离后可以独立测试：

- 决策器是否重复查询、超预算或选到禁区；
- 调度器是否造成饥饿、死锁或无界重试；
- 结果迟到、缺失或乱序时，模型是否等待一致批次；
- 安全层能否在两者都失效时停止。

### 15.5 指标必须覆盖整个系统

只报每小时样本数会奖励快速产生低质量数据。至少报告：

- **吞吐：**单位时间完成且通过质量检查的虚拟观测数；
- **有效率：**有效观测 / 所有尝试，失败按类型保留；
- **决策效率：**固定预算 best-so-far、达到阈值的查询数及不确定性；
- **可靠性：**异常检出、恢复时间、重复查询和数据错配次数；
- **安全性：**越界提案拦截率、误拦截、接管延迟；
- **追踪性：**能否从主张回放到每个选择与原始观测。

## 虚拟实验：材料候选池自动化流水线

### 15.6 范围与组件

使用一个静态表格模拟候选：特征公开，目标标签隐藏在 `virtual_oracle` 中；查询只返回预先保存的数值和质量码，不模拟或指导任何真实制备。组件如下：

1. `planner` 从未查询候选中提出一批 ID；
2. `safety_gate` 拒绝禁用 ID、重复、超预算或批次过大；
3. `scheduler` 按固定容量执行虚拟查询；
4. `analyzer` 检查缺失、范围与质量码；
5. `ledger` 追加不可变事件；
6. `model_updater` 仅使用已通过质量检查的数据；
7. 人工面板可暂停、批准恢复或终止。

### 15.7 比较设计与简单基线

在同一候选池、同一初始样本、同一批大小和总预算下比较：

- **固定脚本基线：**按预先排序或轮询顺序查询；
- **随机基线：**从剩余候选均匀抽样；
- **均值贪心：**选代理模型预测均值最高者；
- **不确定性感知策略：**按预先声明的采集分数选择。

使用多个预定种子报告 best-so-far 中位数、离散范围、达到阈值的查询数和失败次数。Liang 等的池式基准说明 BO 组件必须跨数据集、代理模型和采集函数与随机基线比较；单次漂亮轨迹不足以证明普遍加速（[Liang et al., 2021](https://doi.org/10.1038/s41524-021-00656-9)）。

### 15.8 故障注入

只在虚拟层注入四类故障：结果延迟、一个缺失值、候选 ID 错配、决策器提出禁用 ID。合格系统应分别等待/超时停止、隔离缺失、因身份校验拒绝写入、由独立安全层拦截。记录检测时间、动作、人工接管和恢复依据。

### 15.9 从真实案例学习边界，而非复制操作

A-Lab 把计算数据库、文献提取、机器人、分析和主动学习连接成材料研究系统（[Szymanski et al., 2023](https://doi.org/10.1038/s41586-023-06734-w)）。2026 年作者更正把 40 项原报成功修订为 36 项确认、4 项仅凭 XRD 不确定，并澄清“新”是对预测平台而言（[Author Correction, 2026](https://doi.org/10.1038/s41586-025-09992-y)）。本章只借它说明：自动分析需要独立复核、失败和不确定必须进入闭环；不复述其真实实验参数。

## 常见错误与失败模式

| 现象 | 根因 | 诊断与修复 | 不能推出 |
| --- | --- | --- | --- |
| 吞吐上升但有效数据下降 | 只优化速度 | 以通过质量检查的吞吐计分 | 更快即更好 |
| 结果写错候选 | 身份跨层丢失 | 端到端 ID 与不可变事件检查 | 模型异常必是模型问题 |
| 决策器重复查询 | 状态不同步或重试无界 | 幂等键、预算原子更新、有限重试 | API 成功即新证据 |
| 异常值直接喂给模型 | 在线分析没有质量门 | 隔离、标记并人工复核 | 自动清洗即真实值 |
| 安全规则写在提示词里 | 缺少独立联锁 | 白名单安全层默认停止 | 模型承诺等于控制 |
| 自动判定被写成发现 | 混淆执行、自治与证据 | 独立复核或外部有效性确认，并限定主张层级 | 命中即新知识 |

## 科学有效性与证据检查

- [ ] 是否明确标注全部实验均为虚拟候选查询，不连接真实设备？
- [ ] 高通量、自动化、远程执行和有限自治是否分开描述？
- [ ] 原始观测是否不可变，样本身份能否贯穿所有层？
- [ ] 所有策略是否共享候选池、初始化、预算、批大小和质量规则？
- [ ] 是否包含固定脚本或随机基线、多种子和失败次数？
- [ ] 安全层是否独立于决策器，越界时默认停止并要求人工恢复？
- [ ] 自动分析的不确定结果是否保留为不确定，而非强制二分类？
- [ ] 系统指标是否同时覆盖效率、质量、可靠性、安全和追踪性？

## 练习与评价要点

1. **概念辨析：**为四个系统分别判断高通量、自动化或有限自治。评价要点：依据反馈决策、目标边界和执行方式，不按是否使用机器人判断。
2. **失败诊断：**虚拟系统突然出现性能跃升。评价要点：先查 ID 错配、重复查询、质量过滤和 oracle 泄漏，再讨论算法。
3. **架构实践：**画出动力系统模拟任务的七层架构。评价要点：虚拟执行、独立安全层、不可变数据、停止与人工接管点齐全。
4. **故障注入：**实现四类虚拟故障。评价要点：系统安全停止、日志完整、恢复需明确证据，不追求“总能继续”。

## 本章小结与下一步

自动化实验室是受约束的系统工程：执行、观测、数据、决策和安全必须各自可测试。下一章会把这些组件放入更完整的感知—建模—规划—执行—反馈循环，并明确自治范围由谁定义、何时停止和何时必须交还人类。
