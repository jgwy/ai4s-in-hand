# 引用与事实核验

AI4S 横跨多个学科，错误引用的危害不只是一条链接失效。版本、实验条件或更正状态的差异，可能直接改变教学结论。本规范用于检索、引用、写作和审阅全流程。

## 来源优先级

按下列顺序寻找与核验资料：

1. 原始论文、作者更正、撤稿声明与正式补充材料；
2. 出版社页面、DOI 记录、官方会议论文集和机构仓储；
3. 官方项目文档、数据集说明和代码仓库；
4. 作者或研究机构的权威阐释；
5. 高质量综述与共识报告；
6. 新闻、博客、搜索摘要和产品页面只用于发现线索。

聚合检索、论文搜索和大模型回答可以提高召回率，但不能直接成为重要事实的唯一来源。

## 七项元数据核对

每篇承担关键论点的文献至少核对：

| 字段 | 核对内容 |
| --- | --- |
| 标题 | 与出版版本一致，注意预印本改名 |
| 作者 | 至少核对第一作者、通讯作者或团体作者 |
| 出版载体 | 期刊、会议、预印本或机构报告 |
| 年份 | 区分在线发表、卷期年份和预印本年份 |
| DOI 或稳定标识 | DOI、arXiv ID、PubMed ID 或官方永久链接 |
| 版本 | 预印本版本、accepted manuscript 与 version of record |
| 状态 | 更正、补充、撤稿、表达关注或数据更新 |

当预印本和正式版本同时存在时，优先引用正式版本；如果预印本包含正式版本没有的内容，必须同时说明版本差异。

## 一条事实的核验流程

```text
检索系统找到线索
        ↓
打开出版社/DOI/官方仓储
        ↓
核对元数据与版本状态
        ↓
阅读支持该主张的正文、方法或补充材料
        ↓
检查更正、撤稿与后续数据更新
        ↓
按证据强度改写，并保存稳定链接
```

摘要只适合确认研究范围。涉及具体数字、比较条件、失败原因或方法细节时，应查看正文和方法；涉及数据处理与再分析时，还应检查补充材料或代码。

## 为什么必须检查更正：A-Lab 示例

2023 年 Nature 论文 [*An autonomous laboratory for the accelerated synthesis of inorganic materials*](https://doi.org/10.1038/s41586-023-06734-w) 报告了将机器人、计算数据库、机器学习解释、合成知识和主动学习结合的 A-Lab。2026 年的作者更正说明：

- 原文的“新颖性”表述容易被理解为“对科学界全新”，作者澄清其意图是“对预测平台而言是新的”；
- 对原先报告的 40 个成功结果重新人工分析后，36 个结论得到确认，另 4 个化合物仅凭 X 射线衍射证据无法确定；
- 一个误入训练数据的化合物从相关讨论中移除。

因此，教程不能继续转述未更正版本中的强表述，也不能只修改一个数字而忽略“新颖性”定义和证据判定发生了变化。正确做法是同时链接原文与[作者更正](https://doi.org/10.1038/s41586-025-09992-y)，并以更新后的 HTML/PDF 为准。

这个例子说明：

1. 引用真实论文并不保证表述仍然正确；
2. “新”必须说明是对模型、数据库、实验室还是科学共同体而言；
3. 自动分析结果需要独立复核，复核后的不确定结果不能保留为成功；
4. 更正不是应该隐藏的瑕疵，而是科学自我修正和证据教学的重要材料。

## 大模型与检索系统的使用规则

- 可以用模型生成检索关键词、同义词和候选文献列表；
- 可以用检索增强系统定位可能相关的段落；
- 不复制模型生成的参考文献表后直接发布；
- 不把搜索摘要当成论文全文；
- 每个 DOI 都要解析到对应标题并检查版本状态；
- 多文献综合要检查是否漏掉反例、负结果和不同学派；
- 正文中披露 AI 对检索、整理或写作的实质性参与，责任仍由作者承担。

检索系统返回噪声是正常现象。主题词越宽，结果越可能被高频术语主导；发现噪声后应调整对象、任务、时间和来源限制，而不是要求模型“更认真”。

## 引用格式

正文首次承担关键事实时使用可点击链接；章节末列完整信息。推荐格式：

```markdown
作者. [论文标题](https://doi.org/...). *期刊* **卷**, 页码或文章号 (年份).
```

中文机构报告写明作者或机构、标题、载体与年份。软件和数据集写明版本、发布日期、许可证和永久标识；仅链接滚动更新的主页时，注明核验日期。

## Reviewer 检查表

- [ ] 每个关键事实附近都有能够直接支持它的来源；
- [ ] 来源不是搜索结果页、营销文案或模型回答；
- [ ] 标题、作者、载体、年份、DOI 和版本相互匹配；
- [ ] 已检查出版社的 correction、retraction 和 update 页面；
- [ ] 数字保留了原研究的样本、条件和评价口径；
- [ ] 新闻稿中的强表述已回到论文确认；
- [ ] 综述观点没有被误写成实验结论；
- [ ] 引用内容没有超出原文支持范围。
