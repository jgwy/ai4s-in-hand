# 写作指南

本指南用于统一 AI4S in Hand 的章节结构、叙述顺序和跨学科术语。它既是作者模板，也是 Reviewer 的第一轮检查表。

## 写作目标

每一章都应帮助读者完成一个可检查的认知或实践产物。判断章节是否完成时，不问“覆盖了多少模型”，而问：

- 读者能否把方法放进一个真实科学问题？
- 读者能否说出方法成立所依赖的假设？
- 读者能否运行实验或检查产物？
- 读者能否识别失败情形与证据边界？

## 固定章节结构

正文原则上按以下八项组织。领域特点需要调整时，可以改变小节名称，但不能静默删除相应责任。

```markdown
# 第 N 章：标题

> [!CAUTION]
> 版本状态、已知限制和审阅状态。

## 本章解决的问题
- 3—6 条可验证的学习目标。

## 前置知识与路线
- Science 背景需要补什么；
- AI 背景需要补什么；
- 哪些内容可跳读，依据是什么。

## 核心概念
- 从科学问题或失败案例开始；
- 再给直觉、形式定义、假设与适用边界；
- 公式服务于解释，不服务于复杂度展示。

## 实验或可检查产物
- 数据与代码来源；
- 简单基线；
- 核心方法；
- 运行命令和预期指标范围。

## 常见错误与失败案例
- 错误现象；
- 根因；
- 诊断方法；
- 不能由该结果推出的结论。

## 科学有效性检查
- 数据划分、指标、约束、不确定性、独立复核/外部有效性确认和适用域。

## 练习与延伸任务
- 概念题、诊断题、开放实践题；
- 给出评价标准，不只给“参考答案略”。

## 原始来源与推荐阅读
- 论文、勘误、数据集、代码和官方文档。
```

## 先问题，后方法

不要以“本章介绍 GNN/PINN/Transformer”开场。先说明普通方法在什么科学对象上遇到了什么困难，再引入结构或算法。

推荐顺序：

```text
科学对象 → 任务与证据 → 简单基线 → 基线为何不足
        → 新方法的假设 → 实验比较 → 失败边界 → 科学结论
```

例如，引入图神经网络时，先说明分子由原子及相互作用构成、原子编号通常不应改变性质预测；再讨论图表示与置换不变性。不要从消息传递公式开始，最后才寻找一个分子例子。

## 跨学科术语的三层定义

术语第一次出现时，应同时给出：

1. **直觉：**它试图解决什么问题；
2. **形式定义：**变量、条件与数学关系是什么；
3. **边界：**在哪些条件下会失效或被误用。

示例：

> **分布外泛化**直观上是模型面对不同于训练分布的对象或条件时仍能有效工作。形式上，需要先明确训练分布 $P_{\mathrm{train}}(X,Y)$ 与目标分布 $P_{\mathrm{target}}(X,Y)$ 在哪里发生变化。它不是一个脱离场景的单一分数：新分子骨架、新实验设备和更高温度范围对应不同类型的分布变化。

## 公式、图表与代码

### 公式

- 每个符号首次出现时定义；
- 写明等式成立的条件和单位；
- 推导只保留理解后续方法所需的步骤；
- 数值结果出现前说明计算或测量过程。

### 图表

- 图题应能独立说明对象、变量和比较条件；
- 坐标轴包含量名和单位；
- 颜色之外再使用线型、标记或文字，保证黑白打印和色觉差异下可读；
- 提供替代文本，说明图的关键信息而非只写“结果图”；
- 自动生成图表必须保留生成代码和数据来源。

### 代码与 Notebook

- 正文代码只展示关键逻辑，完整可运行版本放在 Notebook 或脚本；
- 不在代码中写密钥、个人路径或仅作者机器存在的文件；
- 固定随机种子，但同时说明固定种子不能替代多次运行或不确定性分析；
- 输出预期范围，不要求不同硬件产生完全相同的浮点数。

## 提示块约定

```markdown
> [!NOTE]
> 补充背景或定义。

> [!TIP]
> 学习路线、实现技巧或降级路径。

> [!IMPORTANT]
> 影响理解或实验结论的关键条件。

> [!WARNING]
> 可能导致错误结论、复现失败或资源浪费的风险。

> [!CAUTION]
> 安全、科研诚信、版本不稳定或尚未完成审阅的内容。
```

不要连续堆叠提示块，也不要用提示块替代正文论证。

## 主张的四个层级

写作时明确区分：

| 层级 | 推荐表达 | 不应越界为 |
| --- | --- | --- |
| 模型结果 | “模型在该划分下达到……” | 普遍科学规律 |
| 实验或模拟观察 | “在给定条件下观察到……” | 因果机制已确认 |
| 解释性假设 | “一种可能解释是……” | 唯一解释 |
| 经多重证据支持的结论 | “现有证据支持……，适用范围为……” | 无条件真理 |

“证明”“发现”“解决”“自主”等词必须有与其强度匹配的证据。无法核验时，降低表述强度或删除。

## 练习设计

每章至少包含三类练习：

- **概念辨析：**让读者区分相近概念并说明边界；
- **失败诊断：**给出不合理划分、指标或结论，要求定位问题；
- **迁移实践：**把本章框架应用到另一个科学对象。

练习评价标准应列出必须出现的要点和常见错误。开放题可以有多种答案，但不能没有检查标准。

## 审阅门槛

章节进入公开完成状态前，至少通过：

- [ ] 作者自检：结构、链接、公式、代码与来源完整；
- [ ] 技术审阅：方法、实现和复现路径正确；
- [ ] 领域审阅：科学对象、变量、约束和结论边界准确；
- [ ] 目标读者试读：前置知识、节奏和产物可完成；
- [ ] 构建检查：VitePress 构建与内部链接通过。
