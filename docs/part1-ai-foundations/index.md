# 第一部分：面向科学问题的 AI 补给

这一部分是 AI4S 的“翻译层”，主要写给具有自然科学或工程背景、但没有系统学习过机器学习的读者。它不试图补完一整套 AI 课程：通用算法与代码练习可按章节路标定向补齐；这里专注把科学对象、观测、约束和证据翻译成可计算、可验证、可回退的任务。

> [!TIP]
> 如果你已有扎实的 AI 背景，可以先跳到[第二部分](/part2-science-foundations/)，但在进入第三部分前建议完成第 4、5 章。

## 你需要回答的核心问题

面对一个科学问题，先不要急着选模型。请依次问：

1. 我们真正关心的对象、观测量、控制量和目标是什么？
2. 这是预测、模拟、生成、逆问题、优化，还是需要连续选择实验的决策问题？
3. 数据如何产生，哪些样本在科学意义上真的独立？
4. 哪些规律必须由模型尊重，哪些关系可以从数据中学习？
5. 模型的误差会怎样影响下一步科学判断？

## 两类读者的使用方式

### Science 背景读者

建议按第 1—5 章顺序学习。第 1、2 章建立任务和证据的底座；第 3、4 章解释结构与物理先验；第 5 章把单次预测连接成序贯发现过程。

### AI 背景读者

可以把第 1—3 章作为诊断式复习，根据练习结果跳读。第 4、5 章是合流必修：前者解释科学知识如何进入模型，后者解释为什么 AI4S 的终点通常不是一张测试集分数表。

## 进入第三部分前的自检

- [ ] 我能用一句话区分科学问题与机器学习任务。
- [ ] 我能解释为何随机划分可能高估科学模型的泛化能力。
- [ ] 我会先建立简单基线，并说明复杂模型新增了什么假设。
- [ ] 我能区分插值、外推和分布外泛化。
- [ ] 我能说明不确定性如何影响“下一次测什么”。
- [ ] 我能把预测器放进一个包含选择、评估和更新的闭环。
