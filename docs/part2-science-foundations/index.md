# 第二部分：面向 AI4S 的 Science 补给

这一部分主要写给具有 AI、计算机或数据科学背景，但缺少自然科学训练的读者。它不把物理、化学、材料和生命科学各压缩成一章“百科全书”，而是为每个领域建立一套足以开展 AI4S 对话的**最小科学模型**。

> [!TIP]
> 如果你已有自然科学背景，第 6、11 章仍是合流必修；此外请选择一个自己不熟悉的领域章，练习跨学科迁移。

## 什么是“最小科学模型”

每个领域都从同一组问题出发：

| 维度 | 要回答的问题 |
| --- | --- |
| 对象与尺度 | 研究的是粒子、分子、材料、细胞、种群还是连续场？时间与空间尺度多大？ |
| 状态与变量 | 哪些量描述系统，哪些能被观测，哪些只是模型中的隐变量？ |
| 相互作用与约束 | 守恒律、对称性、几何关系、热力学或生物机制施加了什么限制？ |
| 数据如何产生 | 数据来自仪器、模拟、公共数据库还是人工标注？测量误差和选择偏差是什么？ |
| 如何验证 | 预测需要用新实验、独立队列、更高精度计算还是机制一致性检验？ |
| AI 常见错误 | 哪些“看起来合理”的表示、划分或指标在该领域其实没有科学意义？ |

掌握这六个维度，比记住一串模型名称更重要。

## 两类读者的使用方式

### AI 背景读者

建议学习第 6—11 章。不要把领域章当成可跳过的背景故事：科学变量、约束和验证方式会直接改变数据划分、模型结构和评价标准。

### Science 背景读者

第 6 章帮助你把本学科默认的科研常识显式化；第 11 章帮助你比较不同领域的 AI4S 成功条件。再选择一个陌生领域章，尝试用同一框架理解新的科学对象。

## 进入第三部分前的自检

- [ ] 我能区分观测、模型输出与科学主张。
- [ ] 我能说明一个数据点是怎样被实验或模拟产生的。
- [ ] 我能指出至少一条模型必须满足的科学约束。
- [ ] 我知道本领域的“独立测试”在实践中意味着什么。
- [ ] 我能举例说明高预测精度为何仍不足以支持机制结论。
- [ ] 我能与领域专家共同写出目标、约束、风险和验证计划。
