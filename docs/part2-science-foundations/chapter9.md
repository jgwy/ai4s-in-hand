# 第 9 章：材料科学

> [!CAUTION]
> 本章是可公开的 Alpha 初稿。材料制备与表征只讨论证据层级，不提供具体实验操作参数；实际工作必须遵守相应设备、化学品和机构安全规范。

材料模型常从化学式预测一个性能数值，但实验室面对的从来不只是化学式。同一组成可能形成不同晶体结构、缺陷和相；同一结构又会因加工历史、尺寸和测试条件表现不同。若不写清这些条件，“成分到性能”的高分模型很可能只是数据库的快捷索引。

本章用**成分—结构—工艺—性能（composition–structure–processing–property, CSPP）**关系建立材料最小模型，并把计算筛选与实验验证之间的鸿沟放进任务定义。

## 本章解决的问题

完成本章后，你应该能够：

1. 区分成分、晶体结构、相、缺陷、样品与器件层级；
2. 解释周期性、对称性和稳定性如何约束材料表示；
3. 区分计算稳定、可合成、相纯、功能有效和可制造；
4. 识别材料数据库中的选择偏差、重复和负结果缺失；
5. 为多目标筛选定义候选空间、预算和验证阶梯；
6. 完成一份材料设计空间学习卡。

## 核心概念

### 9.1 对象与尺度：材料不是一条化学式

材料对象至少有五个层级：

| 层级 | 典型对象 | 容易遗漏的信息 |
| --- | --- | --- |
| 组成 | 元素比例、掺杂 | 原子如何排列 |
| 晶体/原子结构 | 晶胞、原子坐标、对称性 | 缺陷、无序、表面 |
| 微结构 | 晶粒、相界、孔隙 | 制程与空间异质性 |
| 样品 | 薄膜、粉末、块体 | 尺寸、取向、批次 |
| 器件/服役 | 电极、催化层、结构件 | 界面、环境与长期退化 |

AI 任务必须明确样本落在哪一层。以理想晶体计算的带隙不能未经验证直接代表含缺陷、多相样品的器件表现。

### 9.2 状态与变量：CSPP 关系

可以把材料任务写成条件映射：

$$
\mathbf{p}=f(\mathbf{c},\mathbf{s},\mathbf{r},\mathbf{e}),
$$

其中 $\mathbf{c}$ 是成分，$\mathbf{s}$ 是结构和缺陷状态，$\mathbf{r}$ 是加工/历史，$\mathbf{e}$ 是测量或服役环境，$\mathbf{p}$ 是性能。这个式子只是一张变量清单，不声称存在唯一确定函数。

晶体常用晶格向量与晶胞内原子坐标表示，并通过平移周期复制。描述符或 GNN 应处理原子编号、晶胞选择和周期邻居的一致性。不同晶体结构可有相同组成（多晶型），同一结构原型也可容纳取代、占位无序和缺陷。

### 9.3 相互作用与约束：稳定性是相对概念

材料候选受电荷平衡、几何、对称性、相竞争和热力学等约束。计算筛选常用相对于竞争相凸包的能量 $\Delta E_{\mathrm{hull}}$，单位通常为 eV atom$^{-1}$ 或 meV atom$^{-1}$。在指定计算方法、能量兼容性修正和数据库相集合下，理想数学口径的 $\Delta E_{\mathrm{hull}}=0$ 表示处于计算凸包；实际数据库还会使用数值容差，竞争相集合也可能不完备。小的正值描述相对凸包的亚稳程度，不应直接二分为“不稳定”。无论数值如何，它都不保证动力学可达、在真实条件下稳定，也不保证能制成所需形态。

“稳定”至少要注明：

- 是热力学、动力学、机械、动态还是服役稳定；
- 相对于哪些竞争相、温度/压力和环境；
- 来自何种计算近似或实验观察；
- 指理想晶体、实际样品还是器件。

多目标设计还可能同时要求性能、稳定性、资源可得性、成本与安全。把这些目标早早压成一个加权分数，会隐藏权重选择和 Pareto 权衡。

### 9.4 数据如何产生：数据库是一条计算或实验管线

大规模材料数据库多来自标准化密度泛函理论（DFT）计算。Materials Project 的早期论文说明了如何用高通量计算构建公开材料数据基础设施（[Jain et al., 2013](https://doi.org/10.1063/1.4812323)）。计算一致性使大规模比较成为可能，但数据继承了泛函、赝势、磁态、结构初始化和收敛设置的系统误差。

实验数据还受到合成路径、样品纯度、仪器、分析方法和报告选择影响。文献通常更愿意发表成功与优异性能，失败或“不工作”的条件可能缺失。[Raccuglia et al., 2016](https://doi.org/10.1038/nature17439)展示了把未成功实验也纳入学习对材料反应结果预测的价值；它提醒我们，负结果不是需要删除的脏数据，而是定义可行域的重要证据。

数据审计应检查：

- 同一组成的多晶型和同一结构的重复计算；
- 实验值与计算值是否混在同一标签列；
- 性能是否带温度、方向、频率、厚度等条件；
- 数据库快照、计算兼容性和后续修订；
- 哪些候选从未被尝试，哪些失败没有入库。

### 9.5 表示、任务与多目标筛选

组成描述符适合没有结构信息的早期筛选；晶体图、局部环境和等变三维模型适合结构依赖性质；显微图像适合微结构任务。表示的最大分辨率不会自动提升科学分辨率：如果标签只按化学式聚合，再精细的三维模型也无法恢复缺失的工艺条件。

一个可信筛选流程至少比较：

1. 频率/均值、线性或树模型等简单基线；
2. 结构感知模型；
3. 随机选择或固定规则与主动选择策略；
4. 在相同计算/实验预算下的命中率与最优值轨迹。

划分可按化学体系、结构原型、时间或数据库来源进行。随机拆分近似结构会高估新化学空间的泛化。多目标模型应报告各目标的预测不确定性、约束违反率和候选覆盖，而不只报告综合分数。

### 9.6 如何验证：跨越“筛到”与“做到”

材料证据可按成本逐级推进：

```text
模型预测
  → 同分布与体系外测试
  → 标准化 DFT/高精度计算复核
  → 合成与结构/成分表征
  → 独立性能测量
  → 稳定性、重复批次与器件/服役验证
```

每一步回答不同问题。计算稳定候选不是实验发现；观察到目标衍射特征也不自动证明成分、纯度和功能；一次高性能测量不能证明可制造或长期稳定。失败应回流到候选生成、误差模型和决策策略，而不是从结果表中删除。

### 9.7 AI 常见错误

- 把化学式当作材料全部状态，忽略结构、缺陷和工艺；
- 随机划分结构近邻或同一材料的多个计算记录；
- 把 DFT 标签称为实验真值，把计算凸包稳定称为可合成；
- 只从成功论文构建数据，随后声称模型学到了完整可行域；
- 将“数据库中未收录”“对平台新”和“对科学界全新”混为一谈；
- 优化单一性能而忽略稳定性、成本、安全和资源约束。

## 常见错误与失败案例

| 现象 | 根因 | 诊断 | 不能推出 |
| --- | --- | --- | --- |
| 随机测试误差很低 | 同原型/体系近邻泄漏 | 按体系或原型留出 | 能发现新材料家族 |
| 候选在计算上稳定 | 方法误差、动力学和工艺缺失 | 不同计算近似与实验阶梯 | 一定可合成 |
| 合成样品有目标峰 | 成分、多相或无序仍不确定 | 正交表征与人工复核 | 已确认纯相及功能 |
| 主动学习命中率提高 | 候选池或失败记录偏置 | 固定池、同预算、多策略比较 | 开放材料空间中普遍更优 |

## 科学有效性检查

- [ ] CSPP 四类变量和材料层级均已定义；
- [ ] 性能带单位、方向和测量/计算条件；
- [ ] 周期性、对称性、多晶型和缺陷得到处理；
- [ ] 计算与实验标签没有静默混合；
- [ ] 数据快照、负结果与未尝试区域有记录；
- [ ] 划分对应新体系、新原型或新时间目标；
- [ ] 多目标和预算与简单策略公平比较；
- [ ] 计算稳定、实验合成、功能和发现措辞严格区分。

## 练习与延伸任务

1. **概念辨析：**说明“化学组成相同”为什么不足以定义同一材料样本。评价要点：多晶型、缺陷、微结构、工艺和条件至少三项。
2. **失败诊断：**某带隙模型随机拆分同一材料的多个 DFT 计算。提出去重与划分。评价要点：结构/计算设置聚类、材料级留出、体系外测试。
3. **迁移实践：**为一种虚拟材料筛选填写材料设计空间学习卡。评价要点：新颖性口径、多目标、负结果、预算、验证阶梯和停止条件完整。
