# 第 6 章：科学方法、建模与可信验证

> [!CAUTION]
> 本章是可公开的 Alpha 初稿。它提供跨领域通用的审查语言，不能替代具体学科的统计规范、仪器规范和领域专家审阅。

一个模型把测试误差从 0.20 降到 0.12，说明了什么？它首先说明：在给定数据、划分、指标和实现下，这个模型比对照方法更好地完成了一个计算任务。它不自动说明模型抓住了因果机制，也不自动说明结论能推广到新实验室、新人群或新材料。

本章把“模型跑通”到“科学主张成立”之间缺失的环节显式化。贯穿全章的共同语言仍是序章的四要素：**对象—任务—约束—证据**。

## 本章解决的问题

完成本章后，你应该能够：

1. 区分观测、假设、模型、预测、实验结果和科学主张；
2. 用单位、量纲、尺度和测量过程检查变量定义；
3. 区分相关、因果与机制解释，并写出竞争解释；
4. 区分内部效度、外部效度和构念效度；
5. 区分校准、验证、重复与复现；
6. 完成一张“主张—证据—竞争解释”审查表。

## 前置知识与路线

- **AI 背景读者：**需要知道训练集、测试集、损失和常见指标。请重点读“数据如何产生”和“如何验证”，不要把测试集视为天然独立的真值来源。
- **Science 背景读者：**可略读基本统计术语，但应完整填写本章产物；它把本学科默认的科研常识变成后续跨领域协作可检查的接口。
- **两类读者：**建议先完成[第 0 章的“科学问题初相识”学习卡](/preface/)，再用本章审查其中最强的一条主张。

## 核心概念

### 6.1 对象与尺度：主张究竟指向什么

科学对象不只是数据表中的一行。它可能是一次测量、一个分子、一块样品、一位受试者、一段轨迹或一个连续场。首先写明三种单位：

- **研究单位：**主张针对谁或什么，例如材料批次、患者或天气时刻；
- **观测单位：**仪器实际产生一条记录的单位，例如一次扫描或一个图像块；
- **分析单位：**模型损失函数中被当作样本的单位。

三者不一致时，独立性很容易被高估。把同一患者的多个切片随机分到训练集和测试集，会得到许多“数据点”，却没有得到许多独立患者。把同一分子多个构象拆散，也会造成类似泄漏。

空间、时间和组织层级限定主张的范围。“在秒尺度内预测局部流场”不能静默升级为“解释多年气候变化”；“在纯化蛋白上观察结合”也不能直接升级为“在人体内有效”。

### 6.2 状态与变量：观测不等于真实状态

可以用一个最小测量模型表示数据来源：

$$
y_{\mathrm{obs}} = h(x, c) + \epsilon_{\mathrm{meas}} + \epsilon_{\mathrm{proc}}.
$$

其中，$x$ 是希望了解但未必能直接观测的系统状态，$c$ 是实验或采样条件，$h$ 是测量过程，$y_{\mathrm{obs}}$ 是记录值；$\epsilon_{\mathrm{meas}}$ 表示测量噪声，$\epsilon_{\mathrm{proc}}$ 表示制样、采样或数据处理引入的变化。各项必须在同一量纲下相加。

常见变量角色包括：

| 角色 | 问题 | 例子 |
| --- | --- | --- |
| 观测量 | 仪器或记录实际给出什么？ | 光谱强度、温度、序列计数 |
| 控制量 | 研究者能够设定什么？ | 外加场、采样时刻、候选选择 |
| 状态量 | 哪些量足以描述后续演化？ | 位置与动量、浓度场 |
| 参数 | 哪些量在一次模型运行中固定？ | 反应速率常数、材料系数 |
| 混杂变量 | 什么同时影响输入和结果？ | 批次、年龄、设备、季节 |
| 隐变量 | 什么未直接记录却影响数据？ | 未测环境因素、潜在亚群 |

量值应写成“数值 × 单位”。国际单位制和量纲规则可查阅 BIPM 的 [SI Brochure 第 9 版](https://doi.org/10.59161/AUEZ1291)。归一化后的模型输入可以无量纲，但转换公式、原单位和反变换必须保留。

### 6.3 相互作用与约束：模型是有条件的近似

**假设**是可以接受证据检验的陈述；**模型**是为特定目的保留部分关系、忽略其他细节的形式化表示；**理论**通常连接更广泛的现象并接受了多类证据检验。模型并不因使用方程而成为真理，也不因使用神经网络而没有假设。

约束至少来自四处：

1. 定义和量纲，例如能量不能与长度直接相加；
2. 已知结构，例如对称性、守恒律和边界条件；
3. 数据生成过程，例如检测下限和抽样方案；
4. 决策边界，例如成本、安全和伦理要求。

一个简单基线的价值在于暴露任务本身的结构。时间序列先比较“保持上一时刻不变”，性质预测先比较均值或线性模型。复杂模型只有在相同数据、相同预算和相同评价条件下稳定超过基线，才说明新增复杂度带来了可测收益。

### 6.4 数据如何产生：选择过程也是模型的一部分

数据不是从“真实世界分布”中无摩擦地抽样。实验数据经过对象选择、制备、仪器响应、质控、缺失和人工标注；模拟数据经过方程、参数、初边值条件、离散化与求解器；数据库还经过收录、去重和版本更新。

因此应记录一条 provenance 链：

```text
目标总体 → 纳入/生成规则 → 原始信号 → 处理与质控
         → 样本与标签 → 划分 → 模型输入
```

只保留成功实验会造成选择偏差；只收录容易计算的稳定结构会改变材料空间；用未来信息生成当前标签会造成时间泄漏。划分规则应模拟模型将来真正面对的未知性，而不是只追求样本数均衡。

### 6.5 如何验证：从计算正确到科学可用

**验证（verification）**先问“实现是否正确地求解了所声明的计算问题”；**有效性确认（validation）**再问“这个计算问题和输出是否足以代表目标现实”。两者不能互相替代。

| 层次 | 核心问题 | 典型检查 |
| --- | --- | --- |
| 实现验证 | 代码是否按定义计算？ | 单元测试、守恒检查、极限情形 |
| 数据与测量校准 | 量值是否可追溯且偏差受控？ | 标准样、重复测量、校准曲线 |
| 内部效度 | 观察到的关系是否可能由偏差或混杂造成？ | 对照、随机化、敏感性分析 |
| 构念效度 | 指标是否真的测量目标概念？ | 多种测量、专家审查、代理终点边界 |
| 外部效度 | 结论可推广到哪些对象和条件？ | 新批次、新设备、时间或地点外验证 |

**重复性（repeatability）**通常关注相近条件下重复测量的一致性；**计算复现**关注他人能否用数据、代码和环境重建结果；**独立再现**则要求新团队或新数据重新获得与主张一致的证据。术语在不同机构中略有差异，项目应给出自己的操作定义。

统计显著性回答“若零假设与统计模型成立，数据有多反常”；它不回答效应是否足够大、测量是否有效、机制是否成立或结果是否可推广。应同时报告效应量、区间、不确定性来源和实际意义。

### 6.6 相关、因果、机制与可证伪性

相关表示变量共同变化。因果主张还要说明干预：如果改变 $X$，在给定条件下 $Y$ 会怎样变化。机制解释更进一步，需要连接中间实体、过程和可区分的预测。

观测预测模型可以帮助发现稳定关联，但若训练目标只是最小化预测误差，通常不能仅凭特征重要性推出因果。更强主张需要设计、时间顺序、干预、自然实验或明确的因果假设，并检查竞争解释。

**可证伪性**在实践中意味着提前说明哪些观察会让我们降低对主张的信心。不是任何一次反例都能否定复杂理论，但“无论结果如何都算成功”的说法没有形成有效检验。

### 6.7 AI 常见错误

- 把标签当作无误差真值，忽略测量与标注过程；
- 把交叉验证折数当作独立复现实验次数；
- 从预测相关性、注意力或特征归因直接声称机制；
- 只报告平均分，不报告分组失败、区间和适用域；
- 先看测试集再修改任务，仍把它称为一次独立测试；
- 用“模型发现了规律”概括一个只在单一数据版本上成立的结果。

## 实验或可检查产物

### 主张—证据—竞争解释审查表

选择第一部分或你自己的一个模型，复制并填写：

```markdown
**科学主张审查表**

## 1. 主张
- 一句话主张：
- 层级：模型结果 / 实验或模拟观察 / 解释性假设 / 科学结论
- 对象、尺度与适用条件：
- 哪个结果会削弱或否定它：

## 2. 变量与数据生成
- 研究单位 / 观测单位 / 分析单位：
- 输入、输出、单位与测量方法：
- 纳入、排除、质控和缺失处理：
- 可能的混杂、批次与泄漏：

## 3. 对照证据
- 最简单基线：
- 数据划分为什么对应目标未知性：
- 指标、效应量、区间与失败子组：
- 独立复核、外部有效性确认或复现状态：

## 4. 竞争解释
- 至少两个竞争解释：
- 当前证据能排除什么、不能排除什么：
- 最有信息价值的下一项检验：
```

合格产物不要求主张为真；它要求主张强度与现有证据匹配，并明确下一步怎样区分竞争解释。

## 常见错误与失败案例

| 现象 | 根因 | 诊断 | 不能推出 |
| --- | --- | --- | --- |
| 随机划分分数很高，外部数据骤降 | 近重复样本、批次或群体差异 | 按对象、批次、时间重划分 | 模型已普遍泛化 |
| 模型优于基线但误差区间重叠很大 | 样本少或随机性高 | 多次运行、配对比较、报告区间 | 新方法稳定更优 |
| 特征归因符合常识 | 模型利用了相关信号 | 删除/置换、负对照、干预 | 模型识别了因果机制 |
| 复现代码得到同一图 | 管线可重复，但数据和假设未独立 | 新数据、新团队或不同测量验证 | 科学结论已独立再现 |

## 科学有效性检查

- [ ] 主张层级、对象、尺度和适用条件已写明；
- [ ] 每个物理量都有符号、单位和测量/计算定义；
- [ ] 研究单位、观测单位与分析单位没有被混淆；
- [ ] 数据划分对应未来真正未知的对象或条件；
- [ ] 复杂方法与同预算的简单基线比较；
- [ ] 报告效应量、区间、失败子组和不确定性来源；
- [ ] 相关、因果和机制措辞与证据强度匹配；
- [ ] 更正、数据版本与独立复核/外部有效性确认状态已检查。

## 练习与延伸任务

1. **概念辨析：**解释“校准良好但外部效度差”如何可能。评价要点：分别定义校准与目标总体；给出分布变化例子；不能把校准等同准确。
2. **失败诊断：**某医学图像模型把同一患者的多个切片随机分组并得到 99% 准确率。列出至少三项风险。评价要点：患者级泄漏、类别/设备混杂、目标场景与指标；不能只建议“换更大模型”。
3. **迁移实践：**为分子性质或动力系统模型填写审查表。评价要点：单位、划分、简单基线、可证伪结果和竞争解释全部出现。
