# 第 10 章：生命科学——从层级断点到证据链

> [!CAUTION]
> 本章只讲公开数据、模型评价与证据边界，不提供个体医疗建议、病原体设计或湿实验改造步骤。涉及健康与临床决策时，应由合格专业人员按伦理和监管流程处理。

生命系统很像一座正在营业的城市，而不是一张静止的零件图：DNA 提供可被读取的信息，细胞会按环境选择“读哪一段、读多少、怎样加工”，蛋白质与其他分子共同工作，许多细胞再组成组织。AI 可以在其中预测序列、结构、细胞标签或临床风险，但每跨过一个层级，都要补一段新证据。

本章始终沿着一条路线前进：**生活化直觉 → 层级与断点 → 具体案例 → AI 任务 → 验证与误区 → 生命科学证据链学习卡**。

## 本章解决的问题

完成本章后，你应该能够：

1. 依次解释 DNA、基因、转录本/RNA、蛋白质、细胞、组织和个体/表型；
2. 说明这些层级为什么不是一一对应，并指出一条主张跨过了哪些证据断点；
3. 区分细胞类型与细胞状态，以及分子、细胞和临床表型；
4. 识别测量平台、批次、供体、站点和时间造成的混杂；
5. 为蛋白质结构、单细胞类型识别和临床风险任务选择可信的测试单位；
6. 填写一张可审查的“生命科学证据链学习卡”。

## 10.1 生活化直觉：同一份说明书，为什么得到不同结果

想象两间厨房拿到同一本菜谱。厨师选择了不同章节，备料量不同，烤箱温度和用餐时间也不同，最后的菜不会相同。这个类比只用于提醒我们：**拥有相同 DNA，不等于在同一时刻产生相同 RNA、蛋白质和表型。**

类比也有边界。基因不是一条完整而孤立的菜谱，细胞也不是照字面执行指令的机器；调控序列、分子相互作用、发育历史和环境会共同改变结果。因此，下面每个箭头都应读成“可能通过特定过程关联”，不能读成“前者唯一决定后者”。

```text
DNA → 基因 → 转录本/RNA → 蛋白质 → 细胞 → 组织 → 个体/表型
```

**微型词表：**

- **核苷酸 / 基因组：**核苷酸是 DNA、RNA 的基本小单元；[基因组](https://www.genome.gov/genetics-glossary/Genome)是一份细胞所含的整套 DNA 信息。
- **基因表达：**细胞在特定时间和条件下产生哪些 RNA/蛋白质及产生多少（即基因表达）；参见 [NHGRI Gene Expression](https://www.genome.gov/genetics-glossary/Gene-Expression)。
- **转录：**把基因的 DNA 序列做成 RNA 副本，见 [NHGRI Transcription](https://www.genome.gov/genetics-glossary/Transcription)。
- **翻译：**核糖体读取信使 RNA 的信息并连接氨基酸来合成蛋白质，见 [NHGRI Translation](https://www.genome.gov/genetics-glossary/Translation)。
- **细胞：**生命系统的基本结构和活动单位，可独自生活或与其他细胞合作，见 [NHGRI Cell](https://www.genome.gov/genetics-glossary/Cell)。
- **组织：**许多细胞连同其周围环境按空间关系共同完成一组功能。
- **表型：**可观察或测量的特征，由基因组与环境等共同影响，见 [NHGRI Phenotype](https://www.genome.gov/genetics-glossary/Phenotype)。

### DNA → 基因：材料不等于功能单位

- **DNA** 是由核苷酸组成的分子，基因组 DNA 还包含基因间区、调控区域等。
- **基因**是基因组中的功能单位；它占据 DNA 上的区域，但“有这段 DNA”还没有说明它在何时、何处以及以多大程度被使用。[NHGRI Gene](https://www.genome.gov/genetics-glossary/Gene)也提醒，除蛋白质编码基因外，还有产生功能性 RNA 的基因。
- 同一段 DNA 可以处于不同调控环境；不同细胞通常拥有近似相同的基因组，却会产生不同种类和数量的 RNA、蛋白质。

### 基因 → 转录本/RNA：一次“读取”可以有多个版本

- **转录**把基因相关信息写入 RNA。这里的“转录本”是某次转录与加工得到的 RNA 版本。
- 一个基因可因不同转录起点、终止位置或可变剪接（从同一前体 RNA 选择不同片段组合）产生多个转录本；[NCBI RefSeq Select](https://www.ncbi.nlm.nih.gov/refseq/refseq_select/)明确说明许多基因有多个 RefSeq 转录本和蛋白产物。
- 并非所有 RNA 都编码蛋白质；有些 RNA 本身就发挥功能。因此“一个基因对应一个 RNA”与“每个 RNA 都对应一个蛋白质”都不成立。

### 转录本/RNA → 蛋白质：序列之外还有加工与数量

- 蛋白质由氨基酸链构成。可翻译的 RNA 提供序列信息，但翻译效率、降解、定位和翻译后修饰（蛋白质合成后发生的化学基团添加、移除等变化）都会改变蛋白质的数量与状态。
- 不同转录本可能产生不同蛋白质异构体（同一基因产生、序列或加工形式不同的蛋白质版本）；一个转录本也可以被翻译多次。
- [UniProtKB](https://www.uniprot.org/help/uniprotkb)同时记录序列、功能注释及证据来源，并区分人工审阅与计算注释。这提醒我们：数据库中的“功能”不是由氨基酸序列自动等价推出的。

### 蛋白质 → 细胞：零件形状不等于整机行为

- 蛋白质会折叠、改变构象、被修饰并与其他分子相互作用；它在细胞中的位置和浓度也重要。
- 一个细胞表型通常来自许多分子组成的网络，而不是某一个蛋白质单独决定。
- 预测某个蛋白质的结构，可以提出功能假设，却没有自动证明它在真实细胞环境中的功能、作用机制或相互作用。

### 细胞 → 组织 → 个体/表型：组成、空间与历史开始主导

- 组织不仅是细胞列表，还包含细胞比例、空间位置、细胞间信号和细胞外环境。
- 个体表型由基因型、发育、年龄、暴露、行为和环境共同形成；同一分子变化在不同组织或个体中可能有不同结果。
- 从细胞观察跨到个体或临床结局，需要额外的组织、个体和队列证据，不能靠一条“看起来合理”的故事补齐。

## 10.2 三个容易混淆的坐标轴

### 细胞类型与细胞状态

[OBO Cell Ontology](https://obofoundry.org/ontology/cl.html)提供跨物种描述细胞类型的受控词表。入门时可以这样区分：

| 概念 | 要回答的问题 | 例子 | 重要提醒 |
| --- | --- | --- | --- |
| 细胞类型（cell type） | 这个细胞相对稳定的身份是什么？ | T 细胞、上皮细胞 | 类型边界也可能存在连续谱，标签依赖本体版本和注释规则 |
| 细胞状态（cell state） | 这个细胞此刻处于什么条件或过程？ | 增殖、应激、激活 | 同一类型可有多种状态，状态会随时间和环境改变 |

把“应激中的上皮细胞”强行拆成一个全新细胞类型，或把不同细胞类型的共同应激信号当成身份标记，都会制造标签错误。类型与状态的区分是实用的教学框架，不是说二者永远有锋利边界。

### 分子、细胞与临床表型

“表型”必须带尺度：

- **分子表型：**某蛋白质丰度、修饰、结合或酶活等；
- **细胞表型：**形态、增殖、迁移、分化或应激状态等；
- **临床表型：**症状、诊断、检查结局或随访事件等。

模型若只预测分子表型，不能直接宣称改善了细胞表型；细胞表型的变化也不能直接宣称带来临床获益。每一次尺度跃迁都是证据链的断点。

### 数据点与独立样本

十万颗细胞可能只来自五位供体。若目标是对新供体泛化，这十万个**观测行**至多对应五个供体层级单位；它们能否视为相互独立，还取决于招募方式、供体间亲缘，以及供体是否与批次/站点嵌套或成对采样。同一供体的细胞共享遗传背景、暴露、取样和处理过程；一位患者的多次就诊记录也不是多位患者。同一蛋白家族中的多条同源序列（来自共同祖先，往往序列或结构相近）共享进化历史，也不是彼此无关的样本。

## 10.3 数据如何产生：平台、批次和供体会一起进入模型

以单细胞 RNA 测序为例，数据生成链可写成：

```text
招募供体 → 取组织 → 解离细胞 → 分批建库 → 测序平台
→ 比对与计数 → 质控过滤 → 人工/参考标签 → 模型输入
```

这条链上至少有三类变化：

1. **生物变化：**供体遗传背景、年龄、组织位置、细胞类型和状态；
2. **技术变化：**平台、试剂、测序深度、处理日期、实验室和分析软件版本；
3. **选择与标签变化：**谁被纳入、哪些细胞通过质控、专家按什么规则命名。

**批次效应**是处理流程产生的系统差异。若病例全部在平台 A 测量、对照全部在平台 B 测量，疾病与平台完全混杂，算法无法只靠这批数据分清二者。批次校正也不能凭空创造缺失的对照。

[Luecken 等的单细胞整合基准](https://doi.org/10.1038/s41592-021-01336-8)研究了多实验室、多条件数据中的嵌套批次效应，并权衡批次去除与生物变异保留。它是**整合方法基准**，不是细胞类型分类的数据划分基准；本章用它支持“批次结构复杂且可能嵌套”这一范围有限的事实。

## 10.4 案例一：蛋白质结构预测——预测了什么，没预测什么

### 任务定义

生活化问题是：“只看一条氨基酸序列，能否估计蛋白质在三维空间中的形状？”

| 项目 | 应写清楚的内容 |
| --- | --- |
| 输入 | 目标氨基酸序列，以及模型实际使用的同源序列、多序列比对或模板信息 |
| 输出 | 三维原子坐标或残基间几何关系，以及逐残基/残基对置信度 |
| 参考结构 | 在明确构建体和实验条件下解析的独立结构；记录实验方法、与方法相应的质量/不确定性指标、构建体、条件及未解析区域，例如 X 射线/冷冻电镜的分辨率，或 NMR 的构象集合与约束 |
| 评价层级 | 局部几何、整体折叠、结构域相对位置、复合物界面应分别评价 |
| 数据划分 | 审计训练截止日期，以及测试目标与训练结构的序列/结构同源性 |

[Jumper 等的 AlphaFold 论文](https://doi.org/10.1038/s41586-021-03819-2)报告了 CASP14 盲测中的重大结构预测进展；[RCSB PDB](https://rcsb.org/docs/general-help/computed-structure-models-and-rcsborg)也明确区分实验结构与计算结构模型。二者可以比较，却不是同一种证据。

### 置信度不是外部实验验证

AlphaFold 的 pLDDT 是模型对**局部结构**可靠性的内部估计，PAE 则帮助判断不同区域相对位置的不确定性。[AlphaFold 数据库 FAQ](https://alphafold.ebi.ac.uk/faq)提醒，低置信区域、无序区域、多构象、突变效应以及非蛋白组分都有明确限制。

因此：

- 高 pLDDT 不等于“已用实验结构验证”；
- 高局部置信度不等于结构域相对朝向正确；
- 单体结构不等于复合物相互作用界面正确；
- 结构相似不等于功能相同；
- 结构预测不等于已经证明作用机制、疾病因果或临床有效性。

更稳妥的证据链是：**预测结构 → 与独立结构或正交数据核对 → 提出结合/功能假设 → 在相关环境检验分子功能 → 再检验细胞、个体或临床表型。** 证据走到哪一层，主张就停在哪一层。

### 常见失败诊断

- 测试结构在训练截止日前已公开，或测试蛋白与训练结构高度同源：分数可能反映记忆/模板迁移；
- 只汇报平均结构分数：可能掩盖低置信环区、错误结构域朝向或界面；
- 用数据库中的计算功能注释再“验证”结构推导的功能：两者可能共享同一计算来源，并非独立证据。

## 10.5 案例二：单细胞类型识别——细胞多不等于供体多

### 任务定义

输入通常是每颗细胞的基因计数或其表示，目标标签是专家或参考图谱给出的细胞类型。AI 学的是“从这个测量与标签流程得到的表达模式到标签”的映射，并不是直接看见细胞的本体身份。

[Abdelaal 等的分类基准](https://doi.org/10.1186/s13059-019-1795-z)分别比较了数据集内和跨数据集的自动细胞识别表现，说明“同一数据集内好用”与“跨数据集迁移”是不同问题。标签粒度、未知类型与相近状态还会影响评价。

### 四级数据划分

| 划分 | 测试什么 | 主要风险 |
| --- | --- | --- |
| 细胞级随机划分 | 对同一批供体、平台和标签流程中的相似细胞插值 | (a) 同供体相关性会使误差条过窄、对新供体的主张过于乐观；同一供体仅出现在训练和测试两侧时，先作为相关性与泛化范围问题处理，不自动等于信息泄漏。(b) 若供体 ID 或供体标签、重复细胞，或由全数据/测试集拟合或选择的预处理、特征选择、调参/阈值统计等信息从测试集进入训练或模型选择，就属于信息泄漏 |
| 供体留出（donor-held-out） | 对未见供体的泛化 | 供体数太少时方差大，应报告供体数而不只报告细胞数 |
| 批次留出（batch-held-out） | 对新制备批次、日期或平台条件的稳健性 | 若批次与类型完全混杂，无法单独估计两者 |
| 研究留出（study-held-out） | 对新实验室、队列、平台和注释流程的组合迁移 | 标签体系不一致，需要先对齐本体与未知类规则 |

这里的**供体级划分建议是教学推理**：同一供体的细胞共享上游来源，因而不能当作完全独立的泛化单位。它不是从上述“整合基准”直接推出的分类结论。若预期部署在新研究上，最终测试应尽量留出整项研究；若只能做供体留出，也要明确结论只到“当前研究条件内的新供体”。

### 评价与外部验证

- 同时报每类 F1、宏平均 F1、混淆矩阵、拒识/未知类表现，而不只报总体准确率；
- 分别报告**细胞数**和**供体数（及嵌套/配对结构）**，并尽可能给出逐供体结果；
- 检查模型是否按平台、批次或供体轻易聚类；
- 标记基因和专家复核只能用于**标签一致性审计**；记录它们是否参与原标签生成，若参与，就不能再把它们称为独立验证；
- 只有独立取得、未参与建模且未参与原标签生成的蛋白、空间或功能测量，才可作为正交证据；同时记录验证来源是否与标签来源重合；
- 外部研究标签若粒度不同，不要强行当作同一“真值”。

### 常见失败诊断

若细胞随机划分接近满分、供体留出明显下降，优先检查模型是否记住供体或批次。若整合后所有批次混得很匀，也不能立即宣布成功：真正的细胞状态可能同时被抹去。好的整合必须同时检查批次去除与生物变异保留。

## 10.6 案例三：临床风险——短案例只讨论验证边界

假设用既往就诊记录预测某个预先定义的随访结局。这里不讨论决策阈值、诊断或治疗建议，只审查划分：

- **记录级随机划分**可能把同一患者的多次记录分到训练和测试，造成患者身份与病程泄漏；
- **患者留出（patient-held-out）**检验对新患者的泛化；
- **站点留出（site-held-out）**检验医院人群、设备、编码和流程变化；
- **时间留出（time-held-out）**用较早资料训练、较晚资料测试，接近真实未来使用并暴露流程漂移。

外部验证应来自开发过程之外的患者、站点或时间段，并重新检查区分度、校准和亚组表现。[TRIPOD+AI](https://doi.org/10.1136/bmj-2023-078378)是报告规范，不是模型质量认证。即使外部验证良好，也只支持特定目标人群、站点与时间范围内的预测表现，不自动证明因果、临床净收益或治疗有效性。

## 10.7 从 AI 任务回到证据链

遇到新的生命科学模型，按下面六问停下来：

1. **对象在哪个层级？** 输入是序列、分子测量、细胞、组织图像还是患者记录？
2. **标签在哪个层级？** 是结构、功能、细胞类型、细胞状态还是临床结局？
3. **数据怎样产生？** 平台、批次、供体、站点和时间怎样进入数据？
4. **谁才是独立单位？** 同源家族、供体、患者或站点是否跨集合？
5. **外部验证真的外部吗？** 是否来自新来源，且没有参与特征、阈值或模型选择？
6. **主张跨过了什么断点？** 还缺结构、功能、细胞、个体、因果或临床用途中的哪类证据？

## 常见错误与失败案例

| 现象 | 先查什么 | 能支持的最强结论 | 不能推出 |
| --- | --- | --- | --- |
| AlphaFold 模型局部置信度高 | 训练截止、同源性、PAE、独立实验结构 | 模型对特定局部结构有高内部置信度 | 功能、机制、相互作用或临床有效性已证实 |
| 单细胞随机划分近乎满分 | 供体/批次是否跨集合，标签粒度 | 同研究相似细胞上的插值性能 | 对新供体或新研究泛化 |
| 批次校正后图上混合均匀 | 生物状态和稀有类型是否被抹去 | 表示中的可见批次差异下降 | 真正生物变异完整保留 |
| 临床记录内部测试表现好 | 患者、站点、时间泄漏与校准 | 当前开发样本中的预测表现 | 因果、临床净收益或个体治疗建议 |

## 科学有效性检查

- [ ] 已按顺序写出 DNA → 基因 → 转录本/RNA → 蛋白质 → 细胞 → 组织 → 个体/表型；
- [ ] 已说明可变剪接、调控、环境和多分子网络使层级不是一一对应；
- [ ] 已区分细胞类型、细胞状态，以及分子、细胞、临床表型；
- [ ] 已记录平台、批次、供体、站点、时间和标签流程；
- [ ] 已分别报告观测数（如细胞数）与供体数（及嵌套/配对结构），并说明供体层级独立性假设；
- [ ] 划分单位与真实泛化目标一致，外部数据未参与模型选择；
- [ ] 置信度、内部测试、外部验证和因果/机制证据没有混为一谈；
- [ ] 主张停在证据真正到达的层级。

## 练习与延伸任务

1. **层级辨析：**有人说“同一个基因只产生一个蛋白质，因此可以从基因直接预测临床表型”。请至少指出四个断点。
2. **划分诊断：**某数据集有 120,000 颗细胞、6 位供体。随机按细胞分为训练/测试为什么不等于 120,000 个独立样本？设计供体留出并说明结论范围。
3. **主张降级：**把“高 pLDDT 证明蛋白质能与药物结合并治疗疾病”改写成当前证据真正支持的主张，并列出还缺的证据类型。
4. **完成产物：**为一个公开的分子、单细胞或临床预测任务填写“生命科学证据链学习卡”，再用检查清单逐项审查。
