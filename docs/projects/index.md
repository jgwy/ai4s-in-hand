# 综合项目：最小科学发现闭环

综合项目检验前两部分是否真正合流。学习者不只训练一个预测模型，而是要说明：问题从哪里来、数据如何产生、模型为何可信、下一步为何这样选择，以及最终主张由什么证据支持。

## 首版核心案例

### 案例 A：分子或材料性质预测与序贯筛选

从一个有限候选池出发，建立性质预测基线和不确定性估计，再比较随机选择、贪心选择与贝叶斯优化在固定查询预算下的表现。这个案例连接科学表示、可信划分、代理模型、采集函数和虚拟实验闭环。

### 案例 B：动力系统或 PDE 代理模型

从一个可重复生成的数据系统出发，训练计算成本较低的代理模型，比较其速度、预测误差、外推行为和物理一致性。这个案例连接数值模拟、物理约束、误差传播与模型适用域。

### 扩展案例：蛋白质预训练表示迁移

使用公开预训练表示完成一个小规模下游任务，重点考察数据划分、迁移边界和结果解释，不从头训练大型模型。

## 最小交付物

每个项目必须包含：

1. **问题说明：**科学对象、任务、约束、证据和成功标准；
2. **数据卡：**来源、版本、许可证、样本单位、偏差和划分逻辑；
3. **简单基线：**用于判断复杂方法是否真的增加价值；
4. **核心模型：**实现、假设、训练记录和适用范围；
5. **决策循环：**候选生成或选择策略、预算、停止条件和人工接管点；
6. **验证报告：**指标范围、误差分析、失败案例和独立检查；
7. **证据链：**每项结论对应的数据、图表、代码和文献；
8. **复现入口：**从干净环境运行的命令、随机种子和预期结果范围。

## 最小闭环

```text
提出问题 → 定义任务与证据 → 获取/生成数据 → 建立基线
   ↑                                             ↓
审查结论 ← 独立复核/外部有效性确认 ← 更新数据与模型 ← 选择下一步
```

闭环不以“找到最优候选”自动结束。项目必须预先定义预算、停止条件和无结论时的报告方式。失败结果也是交付物的一部分。

## 安全与范围

首版项目使用公开数据、模拟器或虚拟实验，不要求连接真实湿实验设备。涉及化学、生物和材料实验时，本教程只讨论任务建模、系统架构和安全边界，不提供缺乏专业设施、审批与监督条件下的危险操作指引。

AI 可以帮助生成候选、组织证据和选择下一步，但科学主张仍需经过适当的独立计算、实验或领域审查。项目不得把模型自述、引用数量或一次成功演示当作发现成立的充分证据。
